# 赢了反而亏

「主队夺冠就全额退款」「下雨就免单」这类活动值不值：填售价、成本、搞不搞活动各能卖几件、退多少、你估那件事发生的概率，画成一棵决策树，算期望、万一发生会亏多少、概率低于多少才划算、改哪一项能救回来。

- 在线体验：https://xululu0401.github.io/refund-bet/
- 单文件页面 `index.html` + `core.js`（计算）+ `ui.js`（界面），不联网，输入只存在浏览器本机。
- 测试：`node --test tests/core.test.cjs`；参考实现 `tests/ref.py`（Python Fraction）。
- 默认数字是虚构示例。概率是用户自己的估计，页面不预测任何事件，也不评价任何品牌或活动。
